# v0.5.0 — 会话数据面板

## 新增

- 会话、组、工作区菜单新增「数据」
- 纵向统计行：活动、Token、上下文、费用、工具，点击行展开详情
- 活动行展示轮次、步数、模型用时、工具用时、首 token 延迟和输出速度
- 展示累计 Tokens、缓存命中率、输入/缓存读/缓存写/输出和推理 tokens
- 展示当前上下文占用、轮次和模型
- 展示工具列表、调用次数和失败次数；组/工作区显示并集
- 提供 Token 构成条、上下文构成条和费用构成条
- Token、费用、工具区块支持展开/收起
- 工具列表支持滚轮滚动，并可在「已开放 / 未开放」之间切换
- 「未开放」来自全局工具注册表中未对当前会话可见的工具
- 组/工作区按其中会话聚合，并对嵌套组和子工作区去重
- 非会话不显示首 token / 输出速度；上下文取平均且不显示分布条；工具行只对会话显示
- 金额和上下文估值带 `~`，速度单位使用 `tok/s`
- 支持在「设置 → 会话分组」中填写每百万 token 价格，估算费用

## 说明

- 费用是基于手动配置价格的估算值，不是账单
- 未配置输入/输出价格时不显示金额
- 工具和模型明细依赖 Host 的活跃会话数据；归档会话仍提供 Token 统计
- 组/工作区暂不自动展开子代理会话
