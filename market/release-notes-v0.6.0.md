# v0.6.0 — 删除会话

## 新增

- 会话和组的「移动到分组」改为点击后展开的二级菜单
- 会话 `...` 菜单新增「删除会话」
- 删除前预检运行状态、当前会话和子代理
- 弹窗列出「将执行」的操作，点击按钮立即执行
- 运行中会话会列出停止操作；子代理会话会自动级联，用户 fork 分支保留
- 删除会话日志目录、投影缓存、工作区成员关系和归档/置顶记账
- 能力探测失败时拒绝删除，不降级为裸 `rm`

## 说明

- 删除不可恢复
- 依赖当前 DSH 版本的内部 Session Store / Workspace Registry 接口，不是官方公开 API
- 搜索索引为派生数据，会在下一次观察时自动对账
