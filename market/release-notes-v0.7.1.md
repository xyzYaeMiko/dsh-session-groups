# v0.7.1 — 数据面板扩展化

## 拆分

- 数据面板拆为独立可选插件 `dsh-session-groups-data` v0.1.0
- 核心插件提供 `sessionGroupsUI` protocol 1；数据插件注册 provider 后才显示「数据」入口
- 核心不再包含数据面板、数据菜单、价格设置和 Host `/data` 接口
- 数据插件负责面板渲染、数据抓取、缓存、价格设置、`shell.overlay` 和独立 Host bridge
- 只安装核心：没有数据栏；核心 + 数据扩展：完整功能
- 删除会话仍由核心插件负责，不受扩展影响

## 修复

- 数据面板内部滚动；滚轮不再带动会话栏
- 会话悬浮卡按官方 HoverCard 调整：深色 `#2C2C2E`、244px 宽度、12/16px 内边距、大圆角和 lv3 阴影
- 定时任务时钟补齐 `remote.schedule` 注入，走官方同一套 `schedule/catalog` 数据链路
- 长标题采用官方行级 marquee：悬停去掉省略号、完整名称滚到末尾停住；右键菜单打开时保持滚动位置
- 标题 marquee 的滚动不再关闭已打开的右键菜单
- 原版 → 分组切换只保留列表 200ms 淡入；顶部按钮布局保持原样

## 说明

- 数据插件需要先安装核心插件
- 两个插件不要同时用旧版完整核心加新版数据插件混装
- 核心 Host 的 `/data` 路由已移除；升级后需要完整重启一次 DSH Host
