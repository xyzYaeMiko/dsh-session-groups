# v0.7.0 — DeepSeek 峰谷定价

## 新增

- 适配 DSH 0.2.2：会话悬浮卡、右键菜单、无 hover 操作、归档后续提示

- 删除会话增加安全检测，未通过时禁用删除
- 组/工作区费用只累计可计算会话，缺失数据不再当 0

- 数据面板新增「会话文件」行，显示压缩后的会话日志大小和事件数；组/工作区求和

- 图标改为 G_S 字标：大号彩色渐变 G + 右下灰色小 S
- 数据面板新增「模型」行，按模型使用时间占比展示；组/工作区为时长求和
- 数据面板统计行默认折叠

- 费用估算支持高峰 / 空闲两套价格
- 新安装默认填入 DeepSeek Flash 官方人民币价格（2026-11）；缓存写按未命中输入价
- 设置中分别填写高峰和空闲时段的：
  - 输入
  - 缓存读
  - 缓存写
  - 输出
- 高峰规则：工作日 09:00–12:00、14:00–18:00（Asia/Shanghai）
- 周末和配置的法定节假日按空闲时段计算
- 支持填写法定节假日日期
- 数据面板按会话日志时间戳拆分高峰 / 空闲 token 用量
- 费用明细按高峰 / 空闲分别显示单价、金额和汇总

## 说明

- 搜索仍使用本地标题 / 组名 / 工作区名；官方 Session ID / 内容搜索未移植
- 官方 contextMenus 服务和 sidebar.session.action HOC 尚未接入；定时任务通过 `remoteAccess.whenAccess('schedule/catalog')` 和 `remote.schedule.catalog()` 读取

- 缺少依赖或数据不完整时显示 `—` 并给出说明，不把缺失值当 0
- 模型行缺少时长时只显示最后已知模型，不伪造占比

- 价格仍为手动配置的估算值，不是账单
- 旧版单套价格会自动迁移为高峰和空闲相同的价格
- 归档会话没有逐时段日志数据时，费用按当前时段估算并标注
- 工具和模型明细仍依赖 Host 的活跃会话数据
