# v0.3.0 — 会话分组接入 AI 整理

## 新功能

- 新增 agent 工具 `session_groups`
  - `read`：读取工作区、会话和当前分组结构
  - `apply`：提交完整分组方案，写入前请求用户审核
- 审核使用 DSH approval：只有用户明确批准后才写入；拒绝、取消或审核不可用时不会修改数据
- 方案会校验会话归属、重复引用、完整覆盖和 3 层嵌套限制
- 支持创建 / 改名 / 换色 / 折叠 / 嵌套分组、调整组内会话、放回未分组区

## 约束

- 需要在 DSH Web 的**分组视图**下使用，并保持页面打开
- `apply` 会替换指定工作区的完整分组结构；方案必须覆盖该工作区的每个可见会话且恰好一次
- 分组仍保存在浏览器 localStorage；Host 只负责审核和请求中转

## 升级

- 升级后刷新 DSH Web 页面
- 如果 Host 插件未自动重载，在插件管理中重新启用一次 `session-groups`
