# v0.4.0 — 桌面端支持

## 平台

- 支持 DSH Web
- 支持 DSH Desktop（Electron）：v0.2.1 已在桌面端实测正常；当前版本复用同一套客户端，分组、拖拽、排序、子代理展开和状态联动均可用
- Host 的 Web 桥接依赖改为可选；桌面端没有 `webServer` 时不会阻塞客户端加载
- AI `session_groups` 工具需要本地 Web 桥接；桌面构建提供 Web 服务时同样可用，否则只保留侧栏功能

## 子代理

- 支持展开会话的直接子代理
- 父会话在子代理运行期间显示「子代理运行中」
- 子代理行只在运行中显示转圈，其余状态保持「单人图标 + 名称」布局
