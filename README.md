## 简介

**DSH Session Groups** 是一个 DSH Web 插件。

它受 Microsoft Edge 浏览器的标签页分组启发，把「网页标签可以收进彩色分组」的体验搬到了 DSH 的会话侧栏：把同一个工作区里的会话拖进彩色分组，分组可以折叠、改名、换色、拖动，也可以随时解散。分组只属于当前工作区，不会跨工作区混在一起。

> 这是 v0.1.0 的首个发布版本，主要解决「会话一多，侧栏就乱」的问题。

## 功能

### 像 Edge 标签页一样分组

- 把一条会话拖到另一条会话的**中部**：创建新分组，或加入目标会话所在分组。
- 拖到会话的**上半区 / 下半区**：插入到对应位置，用于普通排序。
- 分组标题栏和未分组会话处于**同一级排序**，可以一起拖动调整位置，不会永远把组压在最上面。
- 支持 8 种分组颜色、双击改名、折叠 / 展开、解散分组。
- 组内会话可以继续拖动排序，也可以拖出分组，或拖到工作区空白处移出。
- 分组严格限制在所属工作区内；跨工作区拖拽会被拒绝。

### 和原版侧栏保持一致

- 顶部「视图选项」可以在**分组视图**和**原版视图**之间切换；原版视图保留 DSH 自带浏览器。
- 会话行保留原版图标和操作：置顶、重命名、分叉、归档 / 取消归档、复制 Session ID。
- 会话状态与官方一致：运行中转圈、等待审批 / 计划待审 / 等待回答、运行结束未读绿点；组折叠时会在组头汇总状态，同状态显示数量。
- 已归档会话默认隐藏，可在「视图选项」里取消隐藏；显示时使用原版灰色标题，并变为不可拖动。
- 会话数量较多时显示「展开其余 N 个会话」，展开后可「收起」；运行中、等待交互、未读完成和当前会话会自动保持可见。
- 工作区 `...` 菜单提供「按时间顺序排列」：按更新时间重排工作区内的分组和会话，组内也同步按时间排序；排序只是一次重排，之后仍可自由拖动。
- 添加工作区使用和官方一致的目录浏览弹窗，支持目录跳转、路径编辑和新建文件夹。
- 视觉使用 DSH 主题 token，跟随明暗主题；没有引入 Harness Client 运行时包，只从模块表加载 React。

## 安装

### 环境要求

- 已安装并运行 **DSH Web**
- DSH 版本满足 `>=0.2.1-rc.2 <0.3.0`
- 当前 Web profile 可安装本地插件

### 方式一：插件管理器

1. 打开 DSH Web 的插件管理面板。
2. 选择「从本地目录安装」。
3. 指向本项目根目录（包含 `package.json`、`cordis.patch.yml` 的目录）。
4. 安装完成后刷新 Web 页面。

### 方式二：命令行

```bash
dsh plugin install /absolute/path/to/dsh-session-groups
```

安装后刷新 DSH Web，侧栏底部会出现分组视图切换按钮。

## 使用

1. 点击侧栏底部的分组视图按钮，进入分组视图。
2. 把会话拖到另一条会话的中间：创建或加入分组。
3. 拖动组头可以调整分组位置；拖动组内会话可以调整组内顺序。
4. 双击组名可以重命名；组头 `...` 菜单可以换色、折叠或解散分组。
5. 需要回到 DSH 原版侧栏时，在「视图选项」里选择「原版视图」。

> 分组、折叠状态和手动排序都保存在当前浏览器的 localStorage 中，不会写入 DSH 的 Session 或 Host 记录。

## 数据与兼容性

- 存储键：`dsh.session-groups.v1`
- 存储内容：分组、颜色、折叠状态、顶层顺序、手动排序、隐藏已归档偏好等**视图状态**。
- 数据是浏览器本地的，不跨浏览器、不跨 profile、不跨 origin 同步；清除站点数据会丢失分组。
- 分组只做视图层重组，不修改会话内容，也不写 Session 事件。
- 插件通过较低优先级替换 `sidebar.workspaces` 区域；禁用或卸载插件后，DSH 原版浏览器会自动恢复。
- 仅支持 DSH Web，不支持 Desktop 端。
